# 理财产品每日收益看板

## 字体字号字重规范（2026-11-19 定稿）

改动样式时遵循以下固定阶梯，勿再新增 0.5px 相邻档位（维护约定，详见字体盘点审核稿）。

### 字号阶梯
| 端 | 档位 | 用途 |
|---|---|---|
| 桌面 | 11 / 12 / 13 / 15 / 21 / 36 | 说明副行 / 表头卡片 / 表格正文 / 强调大数 / 区块标题·指标值 / 主标题 |
| 手机竖屏 | 11 / 12 / 12.5 / 17 / 21 | 说明·年月表 / 表头控件 / 表格正文 / 区块标题·指标值 / 主标题 |
| 手机横屏 | 11.5 / 12 / 13 | 表格正文·表头·说明 / 日历主数值 / 强调 |

犄角上标（如 T+N 角标 sup.nav-lag）保持 9px，属于唯一例外。

### 字重（4 档固定）
- 400：正文、说明
- 600：表头、次级标题
- 700：数值强调、可排序列
- 800：仅主标题

### 颜色与字体
- 辅助/说明文字统一用 `var(--muted)`（#5d6b76，5.48:1，达 WCAG AA），不再新增更浅的灰。
- 中文一律 `var(--font)`，数字/代码一律 `var(--mono)`；移除 Arial 与混排声明（★ 符号按钮除外）。

> 注：本规范已同步进 `PROJECT_NOTES.md`（第 8 节）并登记到守卫清单 protected，两端改动样式时都须遵守。

### 字号专用档（2026-11-20 审核稿 B1 登记）

### 收益与年化口径（2026-11-21 定稿）
- **持仓收益** = 市值 − 当前持仓成本（只算仍持有份额，与建行 App 一致）；**累计收益** = 持仓收益 + 已赎回部分已实现收益。
- **持仓收益率** = 持仓收益 ÷ 当前持仓成本；**持仓年化** = 持仓收益 ÷ 持仓成本 × 365 ÷ **计息天数**。
- **计息天数 = 最新净值日 − 成交净值日**（申购申请日 T 日所在那根净值，不是 T+1 确认日），终点同样取最新净值日、不取「今天」：分子只覆盖到已披露净值的最后一天，分母必须同口径。起点早于产品成立日时以成立日为下限。
- 曾出错：悦享天添24号分母错用确认日→少算 1 天，年化显示 14.51%（实际 7.25%）。现已用三重机制防复发：① `computeHoldings()` 里的 `assertHoldMath()` 对「天数=区间差、终点=最新净值日」做运行时不变量断言，违反即 `console.error` 并写入 `window.__ANN_GUARD_ERRORS__`；② `tools/check_ann.py` 只用原始交易 + 净值序列独立复算，与页面逐项比对（成本/市值/持仓收益/计息天数/年化），并用净值路径年化做交叉校验，异常退出码 1；③ 年化单元格 tooltip 直接摊开算式与计息区间，任何一格都能当场验算。
- **短样本**：计息不足 7 天（`SHORT_ANN_DAYS`）的年化属 1~6 天的线性折算，波动极大，表格里前置 `*` 并置灰，section 下方 `note-line` 有说明。
